3. Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt, einen Dienst von GitHub, Inc. Beim Aufruf einer GitHub-Pages-Seite verarbeitet GitHub technisch erforderliche Verbindungsdaten. Die Verarbeitung dient der sicheren und technisch zuverlässigen Bereitstellung der Website. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO. Das berechtigte Interesse liegt im sicheren Betrieb und in der Fehleranalyse.

4. Lokale Speicherung im Browser

Küchenkumpel speichert einige ausdrücklich gewählte Einstellungen und Listen ausschließlich im lokalen Speicher des verwendeten Browsers. Diese Daten werden durch die App nicht an einen eigenen Server übertragen und dienen nur dazu, Funktionen auf demselben Gerät und in demselben Browser wiederherzustellen.

  • kuechenkumpelThemegewähltes Erscheinungsbild
  • kuechenkumpelHideWelcomeEntscheidung, ob die Begrüßung erneut angezeigt wird
  • kuechenkumpelMoodgewählte Küchenlage
  • kuechenkumpelFavoritesgespeicherte Favoriten
  • kuechenkumpelPantryEinträge der Vorratskammer
  • kuechenkumpelWellnessGoal – das lokal gewählte Ziel im Bereich „Bewusst & lecker“
  • kuechenkumpelShoppingListEinträge des Einkaufszettels
  • kuechenkumpelRecentRecipeszuletzt geöffnete Rezepte
  • kuechenkumpelSeenUpdateVersionzuletzt bestätigter Update-Hinweis

Die lokale Speicherung ist für die jeweils gewählte Komfortfunktion erforderlich. Sie kann jederzeit über die Funktionen der App oder durch das Löschen der Website-Daten im Browser entfernt werden. Küchenkumpel setzt selbst keine Cookies.

Daten werden erst an einen ausgewählten Drittanbieter übergeben, wenn die Nutzerin oder der Nutzer diesen Dienst selbst auswählt.
